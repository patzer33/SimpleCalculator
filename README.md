# 🧮 Simple Calculator

![Java](https://img.shields.io/badge/Java-11%2B-orange?style=flat&logo=java)
![Status](https://img.shields.io/badge/status-complete-brightgreen)

A terminal-based calculator built with Java that supports sequential operations with a clean and colorful interface.

---

## ✨ Features

- ➕ Addition, subtraction, multiplication and division
- 🔁 Sequential operations with partial results
- ⚠️ Division by zero protection
- 🎨 Colored terminal output
- ✅ Invalid operator handling

---

## 🚀 How to run

**1. Clone the repository**
```bash
git clone https://github.com/patzer33/SimpleCalculator.git
```

**2. Compile**
```bash
javac Main.java
```

**3. Run**
```bash
java Main
```
